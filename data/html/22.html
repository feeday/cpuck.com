根据另一张工作表的名单判断数据是否存在

原始表格

工作表：生成文件夹

G列 待查询名称 H列 查询结果
PersonA TRUE
PersonB FALSE
PersonC TRUE
PersonD FALSE
PersonE FALSE

工作表：条件

A列 指定名单
PersonA
PersonC
PersonF

H2 输入：

=COUNTIF('条件'!$A:$A,G2)>0

运行结果

G列 待查询 条件表是否存在 H列查询结果
PersonA 存在 TRUE
PersonB 不存在 FALSE
PersonC 存在 TRUE
PersonD 不存在 FALSE
PersonE 不存在 FALSE

作用： 使用当前工作表 G 列的内容，到「条件」工作表 A 列查找。找到返回 TRUE，找不到返回 FALSE。

其他结果显示方式：

如果不想显示 TRUE/FALSE，而是显示中文：

=IF(COUNTIF('条件'!$A:$A,G2)>0,"存在","不存在")

结果为：存在 / 不存在。

根据英文代号查中文名称

原始表格

A列 中文名 B列 英文代号 C列待查询 D列查询结果
虚构人物甲 PersonA PersonB 虚构人物乙
虚构人物乙 PersonB PersonA 虚构人物甲
虚构人物丙 PersonC PersonD 未找到
虚构人物丁 PersonD PersonD 虚构人物丁

D2 输入：

=XLOOKUP(C2,$B$2:$B$5,$A$2:$A$5,"未找到")

作用： C 列的英文代号去 B 列查找，找到后返回对应 A 列的中文名称。

2. VLOOKUP：根据名称查数量

原始表格

A列人物代号 B列图片数量 C列查询名称 D列结果
PersonA 8 PersonB 6
PersonB 6 PersonA 8
PersonC 5 PersonC 5

D2 输入：

=VLOOKUP(C2,$A$2:$B$4,2,FALSE)

作用： 在 A 列查找人物代号，返回同一行 B 列的图片数量。2 表示返回查询区域第 2 列，FALSE 表示精确匹配。

3. COUNTIF：判断 ID 是否存在

A列已确定ID B列待查ID C列结果
00001 00001 存在
00016 00003 不存在
00031 00031 存在

C2 输入：

=IF(COUNTIF($A$2:$A$4,B2)>0,"存在","不存在")

作用： 检查待查 ID 是否存在于确定名单中。

4. COUNTIF：统计 ID 重复次数

A列原图ID B列出现次数
00001 3
00001 3
00016 2
00001 3
00016 2
00031 1

B2 输入：

=COUNTIF($A$2:$A$7,A2)

作用： 统计当前 ID 在 A 列出现的总次数。

5. COUNTIFS：同时满足两个条件

A列人物 B列模型 C列图片数
PersonA Flux 3
PersonA SDXL 2
PersonA Flux 4
PersonB Flux 5

统计 PersonA 使用 Flux 模型的记录数：

=COUNTIFS(A2:A5,"PersonA",B2:B5,"Flux")

结果：2 条记录

统计符合条件的图片总数：

=SUMIFS(C2:C5,A2:A5,"PersonA",B2:B5,"Flux")

结果：7 张图片

区别： COUNTIFS 统计符合条件的记录数量，SUMIFS 统计符合条件的数值总和。

6. FILTER：根据名单提取完整数据

原始数据：

A列ID B列人物 C列模型
00001 PersonA Flux
00002 PersonA SDXL
00003 PersonB SD1.5
00004 PersonC Flux
00005 PersonD SDXL

指定名单 E2:E3：

E列保留名单
PersonA
PersonD

G2 输入：

=FILTER(A2:C6,ISNUMBER(MATCH(B2:B6,E2:E3,0)),"无结果")

筛选结果：

ID 人物 模型
00001 PersonA Flux
00002 PersonA SDXL
00005 PersonD SDXL

作用： 根据指定人物名单，自动提取所有符合条件的完整数据行。

7. UNIQUE：提取不重复 ID

A列原始ID B列去重结果
00001 00001
00001 00016
00016 00031
00016
00031

B2 输入：

=UNIQUE(A2:A6)

统计去重后的 ID 数量：

=ROWS(UNIQUE(A2:A6))

结果：3 个不同 ID

8. LEFT：提取文件名前五位编号

A列文件名 B列ID
07206_Real_Original_Person_PersonA.png 07206
00001_Original_Person_PersonB.png 00001
00027_Original_Landmark_DemoLandmarkA.png 00027

B2 输入：

=LEFT(A2,5)

作用： 提取文件名前 5 个字符，保留前导零。

9. TEXTAFTER：从路径提取文件名

A2 完整路径：

G:\数据集\Flux\Fake\PersonA\00001_Original_Person_PersonA_7.png

B2 输入：

=TEXTAFTER(A2,"\",-1)

结果：

00001_Original_Person_PersonA_7.png

提取上一级人物文件夹名：

=TEXTBEFORE(TEXTAFTER(A2,"\",-2),"\")

结果：PersonA

10. MID：提取文件名中间内容

A列文件名 B列提取结果
P00001_PS00001_PersonA_Original.png 00001
P00002_PS00001_PersonB_Original.png 00002
P00003_PS00001_PersonC_Original.png 00003

B2 输入：

=MID(A2,2,5)

作用： 从第 2 个字符开始，截取 5 个字符。

11. SEARCH：判断路径是否包含关键词

A列路径或文件名 B列关键词 C列结果
Flux\PersonA\00001.png Flux 包含
SDXL\PersonB\00016.png Flux 不包含
Flux\PersonD\00031.png Flux 包含

C2 输入：

=IF(ISNUMBER(SEARCH(B2,A2)),"包含","不包含")

作用： 根据文件路径中的模型名、人物代号或文件名关键词筛选，不要求整格完全相同。

12. INDEX + MATCH：按英文代号匹配中文名称

A列中文名 B列英文代号 D列查询 E列结果
虚构人物甲 PersonA PersonD 虚构人物丁
虚构人物乙 PersonB PersonA 虚构人物甲
虚构人物丙 PersonC PersonB 虚构人物乙
虚构人物丁 PersonD PersonC 虚构人物丙

E2 输入：

=INDEX($A$2:$A$5,MATCH(D2,$B$2:$B$5,0))

作用： MATCH 找到代号对应的位置，INDEX 返回相应中文名称。适合兼容旧版 Excel/WPS。

13. IFERROR：查找失败时返回指定文字

A列人物 B列数量 C列查询 D列结果
PersonA 8 PersonA 8
PersonB 6 PersonD 未找到

D2 输入：

=IFERROR(VLOOKUP(C2,$A$2:$B$3,2,FALSE),"未找到")

作用： 将 #N/A 等错误替换成指定文字。

14. 条件格式：跨工作表匹配自动标红

假设“生成文件夹”工作表 G 列：

G列人物代号
PersonA
PersonB
PersonC
PersonD

“条件”工作表 A 列有：

A列指定名单
PersonA
PersonC

在“生成文件夹”工作表选中 G2:G1000，设置条件格式公式：

=AND(G2<>"",COUNTIF(INDIRECT("'条件'!$A:$A"),G2)>0)

效果：

  • PersonA：匹配，标红
  • PersonB：不匹配
  • PersonC：匹配，标红
  • PersonD：不匹配

作用： 自动比较不同工作表中的数据，匹配成功的单元格自动标红。

15. AND + COUNTIF：重复数据标红

A列ID 判断结果
00001 重复
00016 不重复
00001 重复
00031 不重复

条件格式公式：

=AND(A2<>"",COUNTIF($A$2:$A$5,A2)>1)

作用： 所有重复出现的 ID 都会标红，包括首次出现的记录。

四、常用公式速查

使用场景 函数 主要作用
英文代号匹配中文名 XLOOKUP 查找并返回对应值
根据 ID 查数量 VLOOKUP 跨列查询
判断 ID 是否存在 COUNTIF 存在性判断
统计 ID 重复次数 COUNTIF 重复统计
按人物和模型统计 COUNTIFS 多条件计数
按人物和模型求和 SUMIFS 多条件求和
按名单筛选完整数据 FILTER 多行数据提取
提取不重复 ID UNIQUE 数据去重
提取文件名前缀 LEFT 字符截取
提取路径文件名 TEXTAFTER 路径解析
提取文件名中间内容 MID 指定位置截取
判断路径关键词 SEARCH 模糊查找
兼容旧版匹配 INDEX+MATCH 组合查找
处理查找错误 IFERROR 错误替换
跨表自动标红 COUNTIF+INDIRECT 跨表匹配
重复值自动标红 AND+COUNTIF 条件格式

实际使用优先掌握的五类

  1. COUNTIF：统计、查重、判断 ID 是否存在。
  2. XLOOKUP：人物、地标名称与编号对应。
  3. FILTER：按名单批量筛选完整数据。
  4. TEXTAFTER：批量解析文件路径和文件名。
  5. COUNTIFS / SUMIFS：按人物、模型、类别统计数量。

注意： 00001、07206 等编号建议使用文本格式保存，避免 Excel/WPS 自动删除前导零。
