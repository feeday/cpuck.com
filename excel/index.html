① C 列筛 A 列 → B 列

A 列是完整 ID，C 列是名单。命中的值回填到 A 所在行的 B 列。

A=00003 · C 含 00003 → B=00003
② 重复 ID 自动高亮

选择 A 列，点击高亮 → 重复值。相同编号的全部记录标上底色。

00001 / 00001 → 标色
③ 公式立即计算

选择空白单元格，输入函数后回车，支持 SUM、COUNTIF、XLOOKUP 等。

=SUM(D2:D6) → 30
