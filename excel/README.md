# CPuck 在线表格

公开入口（当 GitHub Pages 发布生效时）：https://cpuck.com/excel/

本页面取代旧版仅展示公式的查询页，改为原生 JavaScript 的可编辑工作簿。无需服务器处理或传输用户表格内容，直接在电脑及手机浏览器里编辑。所有内置例子均为虚构 ID、虚构样例名称（样例编号 00001 等），不使用真实人物资料。

## 快速使用

- 单元格：点击选择，双击编辑；手机选择后使用顶部 fx 输入栏。
- 工具栏：查找替换、按列筛选、整行排序、求和、高亮、C 列名单筛 A 列并按原行回填 B 列、双列对比、单列/双列唯一值、路径字段提取、向下填充。
- 公式：在单元格输入 `=SUM(D2:D6)`、`=COUNTIF(A:A,"00003")` 或 `=XLOOKUP("00003",A2:A6,D2:D6,"无")`，支持 89 种函数的轻量子集。函数助手可插入示范公式，支持动态数组公式 FILTER / UNIQUE 的溢出显示。
- 多工作表：点击底部标签切换、双击标签重命名、右键标签删除（需保留至少一张）。
- 文件：导入 .xlsx、.xls、.csv、.tsv、.txt、.json；导出多工作表 .xlsx、当前表 .csv/.tsv 或完整 JSON 备份；XLSX 通过官方 SheetJS CDN 按需载入。
- 限制：最多 20,000 行、40 列、30 张表。公式计算器是轻量实现，不保证 100% Excel 兼容；排序时不自动调整所有复杂跨行公式引用。大文件建议在 Excel/WPS 检查和复核。

## C 筛 A，匹配结果放 B 原行

初始示例：

| A 完整 ID | B 输出 | C 指定名单 |
| --- | --- | --- |
| 00001 |  | 00003 |
| 00002 |  | 00005 |
| 00003 |  | 00001 |
| 00004 |  | 00007 |
| 00005 |  | 00009 |

点击 **C 筛 A → B** 后，B2=00001，B4=00003，B6=00005；B3/B5 为空。对应 A 行保持不动。

## 存储 / GitHub Pages

自动保存于当前浏览器 IndexedDB（不可用时回退 localStorage）。换设备、清空浏览器数据、无痕模式切换均可能导致无法访问本地保存内容。请定期导出 JSON 或 XLSX 备份。当前版本**没有跨设备实时协作或云端数据同步**。

仓库 main 分支与 GitHub Pages 会发布同一套网站代码。由于根目录 CNAME 为 cpuck.com，github.io 地址可能重定向到自定义域；这不意味着 GitHub 会同步私人工作簿数据。若需要实际跨设备云同步，需另外建设鉴权和服务端存储方案，不应在公开 GitHub Pages 代码里保存访问令牌。
