# cpuck.com

一个简洁的 AI 资源导航站，收录 AI 模型、图像、视频、音频、多模态、工具及相关文章等资源。

## 首页展示规则

- 首页最多展示 **20 条**资源。
- 分类筛选后同样最多展示 **20 条**。
- 第 21 条及之后的资源不会继续通过下拉加载展示。
- 搜索功能仍基于完整资源库检索，因此未在首页展示的资源依然可以通过关键词搜索找到。
- 文章类内容默认不在首页直接展示，可通过搜索检索。

## 数据来源

主要资源数据位于：

- `data/list.json`
- `data/posts.json`

首页入口：

- `index.html`

## 当前行为

无搜索词时：

```js
currentDataList = currentDataList.slice(0, 20);
```

有搜索词时不会截断结果，会继续对完整 `resources` 数据进行匹配。
